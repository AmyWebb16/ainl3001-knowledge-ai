## Using this repository

Each week's folder contains:

- `README.md` — lab instructions
- `starter.py` — code to begin the lab
- `solution.py` — completed example solution

You should begin with `starter.py` and complete the tasks described
in the week's README.

From Week 4 onwards, some labs will also use reusable code from the
`common` directory.

## Getting the repository

Clone the repository:

    git clone <repository-url>

Then move into the repository:

    cd ainl3001-knowledge-ai

Install the required Python packages:

    pip install -r requirements.txt
